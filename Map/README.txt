ITER Campus Management Map

Run with VS Code Live Server and open index.html.

This revision keeps the supplied campus template as the underlying map geometry and adds:
- Colored, interactive building overlays.
- Administrative, A Block, and B Block shapes aligned to the supplied cluster.
- Clickable hit areas constrained to each colored building shape.
- The supplied top-down football/futsal field image mapped into the original green field footprint.
- Food Court visible but non-clickable.
- Block modal with Lift 1 / Lift 2 and Ground through Floor 5.
- Floor views with Male / Female Washroom actions.
- E Block -> Lift 1 opens a prototype grievance popup for a sample “Lift not working” complaint.
- Other future management destinations remain placeholders with // add link hear in script.js.
